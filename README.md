# Digital Identity Card
A beginner-friendly Python project that displays a digital identity card using variables and print statements.

## Concepts Used
- Variables
- Strings
- Integers
- print() Function

## Sample Information Displayed
- Name
- Age
- Branch
- City
- Dream Job

## Learning Outcome
This project helped me learn:
- How to create and use variables
- How to display formatted output
- Basic Python syntax
